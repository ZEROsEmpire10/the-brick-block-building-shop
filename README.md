# The Brick Block Building Shop

A static, GitHub Pages-ready storefront website for The Brick Block Building Shop.

## Customize before publishing

1. Replace the placeholder address, hours, phone number, and email in `index.html`.
2. Update the Google Maps search URL in the “Get directions” link.
3. Swap the event dates and descriptions for the real calendar.
4. Replace the placeholder contact details and map link before publishing.

## Publish on GitHub Pages

Create a repository, upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root, then enable **Settings → Pages → Deploy from a branch**. Point the domain DNS records at GitHub Pages and add the custom domain under the Pages settings.
